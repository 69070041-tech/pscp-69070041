# บันทึกการแก้โจทย์

ไฟล์นี้ต้องเขียนโดยนักศึกษาด้วยคำพูดของตนเอง

ใช้ template นี้เฉพาะกับโจทย์ OJ ที่ถูกระบุว่าต้องส่ง learning log เท่านั้น

ห้ามให้ AI เขียนไฟล์นี้แทนคุณ AI อาจช่วยตรวจ grammar, formatting หรือความชัดเจนได้ หลังจากที่คุณเขียนเนื้อหาของตนเองแล้ว

ถ้าใช้ AI กับโจทย์ learning-log-required นี้ ต้องทำไฟล์ `ai_reflection.md` ด้วย

## 1. ข้อมูล OJ

หมายเลข/ชื่อโจทย์ OJ:

```text
OJ3115 - [LEARNING LOGS] Arcade of Time: Store Check
```

OJ submission ID ถ้ามีการส่งแล้ว:

```text
588252
```

สถานะ OJ:

```text
Pass
```

เวลาที่ใช้คิดและทำโจทย์ด้วยตนเอง:

```text
15-30 minutes
```

เลือกหนึ่งข้อ:

```text
0-15 minutes
15-30 minutes
30-60 minutes
1-3 hours
3-6 hours
6-24 hours
1-3 days
4-7 days
1-4 weeks
More than 4 weeks
```

วิธีนับเวลา:

- นับเฉพาะเวลาที่ตั้งใจทำโจทย์นี้ด้วยตนเองจริง ๆ
- เริ่มนับตั้งแต่ตอนที่อ่านโจทย์ครั้งแรก
- ไม่นับเวลาพัก กินข้าว เรียน นอน เวลาที่ทำโจทย์อื่น หรือเวลาที่ไม่ได้ทำโจทย์นี้
- ถ้าใช้ AI ให้นับเฉพาะเวลาที่ทำด้วยตนเองก่อน prompt แรกที่ถาม AI
- ถ้าถามเพื่อน TA หรือผู้สอน ให้นับเฉพาะเวลาที่ทำด้วยตนเองก่อนขอความช่วยเหลือครั้งแรก
- ถ้าใช้ทั้ง AI และความช่วยเหลือจากคน ให้นับเฉพาะเวลาที่ทำด้วยตนเองก่อนขอความช่วยเหลือจากภายนอกครั้งแรก ไม่ว่าจะเป็น AI หรือคน
- ถ้าไม่ได้ใช้ AI และไม่ได้ขอความช่วยเหลือจากคน ให้นับเวลาถึงก่อนเขียน `submission.md`
- ประมาณเวลาได้ แต่ต้องซื่อสัตย์

## 2. ความเข้าใจโจทย์ของฉัน

เขียนโจทย์ด้วยคำพูดของตนเอง

ให้อธิบาย input, output และ constraints สำคัญด้วย

ถ้ายังไม่เข้าใจโจทย์ทั้งหมด ให้เขียนสิ่งที่เข้าใจในตอนนี้ ความเข้าใจอาจยังไม่ครบหรืออาจผิดได้ แต่ต้องพยายามอธิบายอย่างจริงใจ

```text
โจทย์ให้คำนวณหาจำนวนร้านค้าที่เปิดให้บริการ ณ เวลาต่างๆ ที่กำหนด โดยเราจะได้รับช่วงเวลาเปิดและปิดของแต่ละร้าน (เปิดที่ start และปิดที่ stop ซึ่งจะเปิดถึงแค่นาทีที่ stop - 1) จากนั้นให้ตอบคำถามว่าในแต่ละเวลา k ที่ระบุเข้ามา มีร้านค้าเปิดอยู่ทั้งหมดกี่ร้าน แล้วแสดงผลลัพธ์ทุกคำตอบในบรรทัดเดียวคั่นด้วยช่องว่าง

Input:
บรรทัดแรกรับจำนวนเต็ม 2 ค่า คือ num (จำนวนร้านค้า) และ check (จำนวนเวลาที่ต้องการตรวจสอบ)
จากนั้น num บรรทัด แต่ละบรรทัดรับจำนวนเต็ม 2 ค่า start และ stop แทนเวลาเปิดและปิดของร้านค้านั้นๆ
บรรทัดสุดท้ายรับเวลาที่ต้องการตรวจสอบจำนวน check ค่าในบรรทัดเดียว คั่นด้วยช่องว่าง

Output:
แสดงผลจำนวนเต็มจำนวน check ค่า ในบรรทัดเดียว คั่นด้วยช่องว่าง โดยแต่ละค่าคือจำนวนร้านที่เปิดอยู่ในเวลานั้นๆ ตามลำดับ

Constraints:
1 <= num <= 10^5
1 <= check <= 10^5
0 <= start < stop <= 1440
0 <= k <= 1440 (เวลาที่ตรวจสอบแต่ละค่า)
เวลาเปิดและปิดเป็นนาทีในรอบ 1 วัน (0 ถึง 1440) โดยร้านเปิดตั้งแต่ start ถึง stop - 1 เท่านั้น (นาทีที่ stop ร้านปิดแล้ว)
```

## 3. แผนแรกของฉัน

เขียนแผนแรกก่อนรับความช่วยเหลือจาก AI เพื่อน TA ผู้สอน หรือก่อนสรุป code สุดท้าย

ถ้าใช้ AI ให้เขียนแผนที่มีอยู่ก่อน prompt แรกที่ถาม AI

ถ้าถามเพื่อน TA หรือผู้สอน ให้เขียนแผนที่มีอยู่ก่อนถาม

ถ้าไม่ได้ใช้ AI และไม่ได้ขอความช่วยเหลือจากคน ให้เขียนแผนที่มีอยู่ก่อนหรือระหว่างเริ่มเขียน code

แผนนี้เขียนแบบคร่าว ๆ ได้ อาจยังไม่สมบูรณ์หรืออาจต่างจากวิธีสุดท้าย

สามารถเขียนเป็น pseudocode, flowchart idea หรือขั้นตอนความคิดได้

```text
Step 1: รับค่า num (จำนวนร้าน) และ check (จำนวนคำถาม) จากบรรทัดแรก
Step 2: สร้างลิสต์ diff ขนาด 1443 ช่อง เริ่มต้นเป็น 0 ทั้งหมด เพื่อใช้เทคนิค Difference Array ในการบันทึกการเปลี่ยนแปลงของจำนวนร้านในแต่ละนาที
Step 3: วนลูป num รอบ เพื่อรับ start และ stop ของแต่ละร้าน โดยกำหนดให้ diff[start] += 1 (ร้านเริ่มเปิด) และ diff[stop] -= 1 (ร้านปิดบริการ)
Step 4: สร้างลิสต์ count เพื่อเก็บจำนวนร้านที่เปิดอยู่จริงในแต่ละนาที โดยคำนวณผลรวมสะสม (Prefix Sum) จาก diff ผ่านตัวแปร running ตั้งแต่นาทีที่ 0 ถึง 1442
Step 5: รับค่าเวลาที่ต้องการตรวจสอบ check ค่าจากบรรทัดสุดท้าย
Step 6: วนลูป check รอบ นำเวลา k แต่ละค่าไปดึงคำตอบจาก count[k] แปลงเป็นสตริงแล้วเก็บลงในลิสต์ results
Step 7: นำข้อมูลใน results มาเชื่อมต่อกันด้วยช่องว่างผ่าน ' '.join(results) แล้วพิมพ์ออกมาในบรรทัดเดียว

ก่อนเริ่มเขียน ฉันคิดว่าจะวนลูปตรวจสอบร้านค้าทั้งหมดในทุกๆ คำถาม แต่เนื่องจาก num และ check มีมากถึง 10^5 การวนลูปซ้อนกันจะทำให้ Time Limit Exceeded (เกิน 1 วินาที) แน่นอน จึงเลือกใช้เทคนิค Difference Array ร่วมกับ Prefix Sum เพื่อให้เตรียมข้อมูลล่วงหน้าได้ในเวลา O(MAXT) และตอบแต่ละคำถามได้ทันทีใน O(1)
```

## 4. วิธีสุดท้ายที่ใช้จริง

อธิบายสั้น ๆ ว่า algorithm หรือวิธีสุดท้ายที่ใช้จริงใน code ที่ส่งคืออะไร

หัวข้อนี้ต่างจาก Section 3:

- Section 3 คือแผนแรกก่อนใช้ AI ก่อนรับความช่วยเหลือจากคน หรือก่อนเขียน code สุดท้าย
- Section 4 คือวิธีสุดท้ายที่ใช้ใน solution จริง
- ถ้าวิธีสุดท้ายเหมือนกับแผนแรก ให้เขียนว่าเหมือนกัน และอธิบายสั้น ๆ ว่าทำไม

ห้ามคัดลอกคำอธิบายจาก AI

ห้ามคัดลอกคำอธิบายจากคนอื่น

```text
วิธีสุดท้ายของฉันเหมือนกับแผนที่วางไว้ โดยรับค่า num และ check เข้ามา จากนั้นสร้าง Difference Array (diff) ขนาด 1443 เพื่อมาร์กการเปิด-ปิดร้านตามช่วงเวลา start และ stop (diff[start] += 1, diff[stop] -= 1) แล้วหา Prefix Sum สะสมค่าใส่ลิสต์ count เพื่อให้ได้จำนวนร้านที่เปิดจริงในทุกๆ นาที จากนั้นรับคำถามเวลา k ทั้งหมดมาดึงค่าจาก count[k] แล้วใช้ ' '.join() แสดงผลลัพธ์ในบรรทัดเดียว ซึ่งสามารถตอบคำถามจำนวนมากได้ทันทีโดยไม่เกินขีดจำกัดเวลา 1 วินาที และรองรับกรณีที่เวลาซ้อนทับกันหลายร้านหรือไม่มีร้านใดเปิดเลย
```

## 5. การทดสอบของฉัน


```text
2 3
0 1440
300 900
0 600 1440
```

Expected output:

```text
1 2 0
```

```text
1 2 0
```

```text
Pass
```

## 7. ความช่วยเหลือจากคน / การร่วมมือ

ได้ถามเพื่อน TA ผู้สอน หรือบุคคลอื่นเพื่อขอความช่วยเหลือในโจทย์นี้หรือไม่

```text

```

ถ้าใช่ ให้อธิบายสั้น ๆ ว่าได้รับความช่วยเหลือแบบใด

ตัวอย่างที่อนุญาต:

- อธิบายความหมายของโจทย์
- อธิบาย concept การเขียนโปรแกรม
- ให้ hint เกี่ยวกับแนวทาง
- คุยเรื่อง debugging
- คุยเรื่อง test cases
- ช่วยอธิบาย error message

สิ่งที่ไม่อนุญาต:

- คัดลอก code ของผู้อื่น
- ส่ง solution ของผู้อื่น
- ขอให้ผู้อื่นเขียน solution ให้
- ใช้ OJ submission ของผู้อื่น
- ขอให้ผู้อื่นส่ง OJ แทน
