# บันทึกการแก้โจทย์

ไฟล์นี้ต้องเขียนโดยนักศึกษาด้วยคำพูดของตนเอง

ใช้ template นี้เฉพาะกับโจทย์ OJ ที่ถูกระบุว่าต้องส่ง learning log เท่านั้น

ห้ามให้ AI เขียนไฟล์นี้แทนคุณ AI อาจช่วยตรวจ grammar, formatting หรือความชัดเจนได้ หลังจากที่คุณเขียนเนื้อหาของตนเองแล้ว

ถ้าใช้ AI กับโจทย์ learning-log-required นี้ ต้องทำไฟล์ `ai_reflection.md` ด้วย

---

## 1. ข้อมูล OJ

หมายเลข/ชื่อโจทย์ OJ:

```text
OJ3233 - [LEARNING LOGS] สลากกินแบ่ง
```

OJ submission ID ถ้ามีการส่งแล้ว:

```text
	649294
```

สถานะ OJ:

```text
Pass
```

เวลาที่ใช้คิดและทำโจทย์ด้วยตนเอง:

```text
15-30 minutes
```

เลือกหนึ่งข้อ:

```text
0-15 minutes
15-30 minutes
30-60 minutes
1-3 hours
3-6 hours
6-24 hours
1-3 days
4-7 days
1-4 weeks
More than 4 weeks
```

วิธีนับเวลา:

- นับเฉพาะเวลาที่ตั้งใจทำโจทย์นี้ด้วยตนเองจริง ๆ
- เริ่มนับตั้งแต่ตอนที่อ่านโจทย์ครั้งแรก
- ไม่นับเวลาพัก กินข้าว เรียน นอน เวลาที่ทำโจทย์อื่น หรือเวลาที่ไม่ได้ทำโจทย์นี้
- ถ้าใช้ AI ให้นับเฉพาะเวลาที่ทำด้วยตนเองก่อน prompt แรกที่ถาม AI
- ถ้าถามเพื่อน TA หรือผู้สอน ให้นับเฉพาะเวลาที่ทำด้วยตนเองก่อนขอความช่วยเหลือครั้งแรก
- ถ้าใช้ทั้ง AI และความช่วยเหลือจากคน ให้นับเฉพาะเวลาที่ทำด้วยตนเองก่อนขอความช่วยเหลือจากภายนอกครั้งแรก ไม่ว่าจะเป็น AI หรือคน
- ถ้าไม่ได้ใช้ AI และไม่ได้ขอความช่วยเหลือจากคน ให้นับเวลาถึงก่อนเขียน `submission.md`
- ประมาณเวลาได้ แต่ต้องซื่อสัตย์

## 2. ความเข้าใจโจทย์ของฉัน

เขียนโจทย์ด้วยคำพูดของตนเอง

ให้อธิบาย input, output และ constraints สำคัญด้วย

ถ้ายังไม่เข้าใจโจทย์ทั้งหมด ให้เขียนสิ่งที่เข้าใจในตอนนี้ ความเข้าใจอาจยังไม่ครบหรืออาจผิดได้ แต่ต้องพยายามอธิบายอย่างจริงใจ

```text
โจทย์ให้ตรวจรางวัลสลากกินแบ่งของกระต่ายน้อย โดยรับผลรางวัลที่ออกและสลากที่กระต่ายน้อยซื้อเข้ามา (แต่ละใบประกอบด้วยหมวดตัวอักษรและเลขสลาก 5 หลัก คั่นด้วยช่องว่าง) จากนั้นนำมาตรวจสอบเงื่อนไขเงินรางวัลตามลำดับมูลค่ามากไปน้อย (ตรงทั้งหมวดและเลข 5 ตัวได้ 1,000,000 / เลข 5 ตัวตรงแต่หมวดไม่ตรงได้ 100,000 / เลขท้าย 3 ตัวตรงและหมวดตรงได้ 2,000 / เลขท้าย 2 ตัวตรงและหมวดตรงได้ 1,000 / เลขท้าย 3 ตัวตรงแต่หมวดไม่ตรงได้ 200 / เลขท้าย 2 ตัวตรงแต่หมวดไม่ตรงได้ 100 / หมวดตรงอย่างเดียวได้ 20) หากไม่ถูกรางวัลใดๆ เลยให้แสดงผล 0 โดยผู้ถูกรางวัลจะได้รับเงินรางวัลสูงสุดเพียงรางวัลเดียวเท่านั้น

Input:
ข้อมูลนำเข้ามี 2 บรรทัด
บรรทัดที่ 1: ผลการออกรางวัล ประกอบด้วยหมวดตัวอักษร และหมายเลขสลาก 5 หลัก คั่นด้วยช่องว่าง
บรรทัดที่ 2: สลากที่กระต่ายน้อยซื้อ ประกอบด้วยหมวดตัวอักษร และหมายเลขสลาก 5 หลัก คั่นด้วยช่องว่าง

Output:
แสดงผลจำนวนเต็ม 1 บรรทัด เป็นจำนวนเงินรางวัลสูงสุดที่ได้รับ หรือแสดง 0 หากไม่ถูกรางวัลใดๆ

Constraints:
หมวดตัวอักษรเป็นตัวอักษรภาษาอังกฤษตัวพิมพ์ใหญ่
หมายเลขสลากเป็นตัวเลข 5 หลัก
ผู้ซื้อจะได้รับเฉพาะรางวัลที่มีมูลค่าสูงสุดเพียงรางวัลเดียวเท่านั้น
```

## 3. แผนแรกของฉัน

เขียนแผนแรกก่อนรับความช่วยเหลือจาก AI เพื่อน TA ผู้สอน หรือก่อนสรุป code สุดท้าย

ถ้าใช้ AI ให้เขียนแผนที่มีอยู่ก่อน prompt แรกที่ถาม AI

ถ้าถามเพื่อน TA หรือผู้สอน ให้เขียนแผนที่มีอยู่ก่อนถาม

ถ้าไม่ได้ใช้ AI และไม่ได้ขอความช่วยเหลือจากคน ให้เขียนแผนที่มีอยู่ก่อนหรือระหว่างเริ่มเขียน code

แผนนี้เขียนแบบคร่าว ๆ ได้ อาจยังไม่สมบูรณ์หรืออาจต่างจากวิธีสุดท้าย

สามารถเขียนเป็น pseudocode, flowchart idea หรือขั้นตอนความคิดได้

```text
Step 1: รับค่าบรรทัดแรกแยกเป็นหมวดรางวัล (prize_set) และเลขรางวัล (prize_num)
Step 2: รับค่าบรรทัดที่สองแยกเป็นหมวดที่ซื้อ (buy_set) และเลขที่ซื้อ (buy_num)
Step 3: ตรวจสอบความตรงกันของหมวดตัวอักษรเก็บไว้ในตัวแปรบูลีน is_set_match = (prize_set == buy_set)
Step 4: ใช้โครงสร้าง if-elif-else ตรวจสอบเงื่อนไขเรียงตามลำดับมูลค่ารางวัลจากมากที่สุดลงไปน้อยที่สุด:
        - ตรงทั้งหมวดและเลข 5 ตัว (is_set_match and prize_num == buy_num) -> พิมพ์ 1000000
        - หมวดไม่ตรงแต่เลข 5 ตัวตรง (not is_set_match and prize_num == buy_num) -> พิมพ์ 100000
        - เลขท้าย 3 ตัวตรง (index 2 เป็นต้นไป) และหมวดตรง -> พิมพ์ 2000
        - เลขท้าย 3 ตัวตรง แต่หมวดไม่ตรง -> พิมพ์ 200
        - เลขท้าย 2 ตัวตรง (index 3 เป็นต้นไป) และหมวดตรง -> พิมพ์ 1000
        - เลขท้าย 2 ตัวตรง แต่หมวดไม่ตรง -> พิมพ์ 100
        - หมวดตัวอักษรตรงอย่างเดียว (is_set_match) -> พิมพ์ 20
        - กรณีอื่นนอกเหนือจากนี้ -> พิมพ์ 0

ก่อนเริ่มเขียน ฉันคิดว่าจะเขียนฟังก์ชันตรวจแยกแต่ละรางวัลแล้วหาค่า max() แต่การใช้ if-elif เรียงลำดับจากรางวัลมูลค่ามากไปหาน้อย ร่วมกับการตัดสตริง (slicing) [2:] และ [3:] เพื่อเทียบเลขท้าย ทำให้ตอบรางวัลสูงสุดได้ทันทีและโค้ดตรงไปตรงมา
```

## 4. วิธีสุดท้ายที่ใช้จริง

อธิบายสั้น ๆ ว่า algorithm หรือวิธีสุดท้ายที่ใช้จริงใน code ที่ส่งคืออะไร

หัวข้อนี้ต่างจาก Section 3:

- Section 3 คือแผนแรกก่อนใช้ AI ก่อนรับความช่วยเหลือจากคน หรือก่อนเขียน code สุดท้าย
- Section 4 คือวิธีสุดท้ายที่ใช้ใน solution จริง
- ถ้าวิธีสุดท้ายเหมือนกับแผนแรก ให้เขียนว่าเหมือนกัน และอธิบายสั้น ๆ ว่าทำไม

ห้ามคัดลอกคำอธิบายจาก AI

ห้ามคัดลอกคำอธิบายจากคนอื่น

```text
วิธีสุดท้ายของฉันเหมือนกับแผนที่วางไว้ โดยรับข้อมูลทั้ง 2 บรรทัดแล้วแยกเป็นหมวดตัวอักษรกับหมายเลขสลาก จากนั้นสร้างตัวแปรบูลีน is_set_match เพื่อเช็คว่าหมวดตัวอักษรตรงกันหรือไม่ แล้วใช้เงื่อนไข if-elif เรียงตรวจตามมูลค่ารางวัลจากมากไปหาน้อย โดยใช้การเปรียบเทียบสตริงธรรมดาสำหรับเลข 5 หลัก และใช้ string slicing [2:] สำหรับเลขท้าย 3 ตัว และ [3:] สำหรับเลขท้าย 2 ตัว ซึ่งทำให้เมื่อตรงกับรางวัลที่ใหญ่ที่สุดแล้วโปรแกรมจะพิมพ์ตัวเลขออกมาและข้ามเงื่อนไขที่เหลือทันที และหากไม่ตรงเงื่อนไขใดเลยก็จะตกไปที่ else เพื่อพิมพ์ 0 ซึ่งครอบคลุมทุกกรณีรางวัลได้อย่างถูกต้อง
```

## 7. ความช่วยเหลือจากคน / การร่วมมือ

ได้ถามเพื่อน TA ผู้สอน หรือบุคคลอื่นเพื่อขอความช่วยเหลือในโจทย์นี้หรือไม่

```text

```

ถ้าใช่ ให้อธิบายสั้น ๆ ว่าได้รับความช่วยเหลือแบบใด

ตัวอย่างที่อนุญาต:

- อธิบายความหมายของโจทย์
- อธิบาย concept การเขียนโปรแกรม
- ให้ hint เกี่ยวกับแนวทาง
- คุยเรื่อง debugging
- คุยเรื่อง test cases
- ช่วยอธิบาย error message

สิ่งที่ไม่อนุญาต:

- คัดลอก code ของผู้อื่น
- ส่ง solution ของผู้อื่น
- ขอให้ผู้อื่นเขียน solution ให้
- ใช้ OJ submission ของผู้อื่น
- ขอให้ผู้อื่นส่ง OJ แทน
