## 2. ความเข้าใจโจทย์ของฉัน

เขียนโจทย์ด้วยคำพูดของตนเอง

ให้อธิบาย input, output และ constraints สำคัญด้วย

ถ้ายังไม่เข้าใจโจทย์ทั้งหมด ให้เขียนสิ่งที่เข้าใจในตอนนี้ ความเข้าใจอาจยังไม่ครบหรืออาจผิดได้ แต่ต้องพยายามอธิบายอย่างจริงใจ

```text
โจทย์ให้เรียงลำดับจุดพิกัด (X, Y) จำนวน N จุด สำหรับแต่ละชุดข้อมูลทดสอบ (มีทั้งหมด T ชุด) โดยกำหนดเงื่อนไขการเรียงลำดับคือ ให้เรียงตามผลรวมของพิกัด f(x, y) = x + y จากค่าน้อยไปหาค่ามาก แต่หากมีจุดใดที่มีค่าผลรวมเท่ากัน ให้เรียงโดยเอาจุดที่มีค่าแกน Y มากกว่าขึ้นก่อน แล้วแสดงพิกัดที่เรียงลำดับเสร็จแล้วทีละบรรทัด

Input:
บรรทัดแรกรับจำนวนเต็ม T แทนจำนวนชุดข้อมูลทดสอบ
จากนั้นแต่ละชุดข้อมูลทดสอบจะประกอบด้วย:
- บรรทัดแรกของชุดทดสอบรับจำนวนเต็ม N แทนจำนวนจุด
- อีก N บรรทัด แต่ละบรรทัดรับจำนวนเต็มสองจำนวน X และ Y คั่นด้วยช่องว่าง

Output:
พิมพ์พิกัด X และ Y ที่เรียงลำดับตามเงื่อนไขแล้ว บรรทัดละหนึ่งจุด ต่อเนื่องกันไปตามลำดับของแต่ละชุดทดสอบ

Constraints:
1 <= T <= 5
1 <= N <= 100
-10,000 <= X, Y <= 10,000
ไม่มีคู่ของจุดใดๆ ที่อยู่ที่พิกัดเดียวกัน
พิกัดสามารถเป็นจำนวนเต็มศูนย์หรือจำนวนเต็มลบได้
```

## 3. แผนแรกของฉัน

เขียนแผนแรกก่อนรับความช่วยเหลือจาก AI เพื่อน TA ผู้สอน หรือก่อนสรุป code สุดท้าย

ถ้าใช้ AI ให้เขียนแผนที่มีอยู่ก่อน prompt แรกที่ถาม AI

ถ้าถามเพื่อน TA หรือผู้สอน ให้เขียนแผนที่มีอยู่ก่อนถาม

ถ้าไม่ได้ใช้ AI และไม่ได้ขอความช่วยเหลือจากคน ให้เขียนแผนที่มีอยู่ก่อนหรือระหว่างเริ่มเขียน code

แผนนี้เขียนแบบคร่าว ๆ ได้ อาจยังไม่สมบูรณ์หรืออาจต่างจากวิธีสุดท้าย

สามารถเขียนเป็น pseudocode, flowchart idea หรือขั้นตอนความคิดได้

```text
Step 1: รับค่าจำนวนเต็ม test_cases (T) จากบรรทัดแรก เพื่อบอกจำนวนรอบของชุดข้อมูลทดสอบ
Step 2: วนลูปตามจำนวน test_cases เพื่อประมวลผลฟังก์ชัน solve_test_case ทีละชุด
Step 3: ในแต่ละชุดข้อมูลทดสอบ รับค่า point_count (N) จากบรรทัดแรก
Step 4: สร้างลิสต์เปล่า points แล้ววนลูป N รอบเพื่อรับพิกัด pos_x และ pos_y แปลงเป็น int แล้วเก็บในรูปแบบ tuple (pos_x, pos_y) ลงใน points
Step 5: สร้างฟังก์ชัน get_sort_key(point) เพื่อคืนค่า tuple สำหรับเรียงลำดับ (pos_x + pos_y, -pos_y) โดย pos_x + pos_y จะเรียงจากน้อยไปมาก และ -pos_y จะช่วยกลับด้านค่า Y ให้ตัวที่ค่ามากกว่าถูกจัดมาก่อน
Step 6: จัดเรียงลิสต์ points ด้วยคำสั่ง points.sort(key=get_sort_key)
Step 7: วนลูปพิมพ์พิกัด pos_x และ pos_y แต่ละจุดออกมาทีละบรรทัดด้วย f"{pos_x} {pos_y}"

ก่อนเริ่มเขียน ฉันคิดว่าจะเขียนลูปเปรียบเทียบสลับตำแหน่งทีละคู่ (Bubble Sort) หรือเขียนเงื่อนไข if-else หลายชั้น แต่การใช้ method .sort() ของ Python ร่วมกับคีย์ที่เป็น tuple (x + y, -y) ช่วยจัดการเงื่อนไขสองลำดับได้ทันที โดยการติดลบที่ค่า y (-pos_y) ทำให้เรียงค่า y มากไปน้อยได้โดยไม่ต้องเขียนโค้ดแยก
```

## 4. วิธีสุดท้ายที่ใช้จริง

อธิบายสั้น ๆ ว่า algorithm หรือวิธีสุดท้ายที่ใช้จริงใน code ที่ส่งคืออะไร

หัวข้อนี้ต่างจาก Section 3:

- Section 3 คือแผนแรกก่อนใช้ AI ก่อนรับความช่วยเหลือจากคน หรือก่อนเขียน code สุดท้าย
- Section 4 คือวิธีสุดท้ายที่ใช้ใน solution จริง
- ถ้าวิธีสุดท้ายเหมือนกับแผนแรก ให้เขียนว่าเหมือนกัน และอธิบายสั้น ๆ ว่าทำไม

ห้ามคัดลอกคำอธิบายจาก AI

ห้ามคัดลอกคำอธิบายจากคนอื่น

```text
วิธีสุดท้ายของฉันเหมือนกับแผนที่วางไว้ โดยใน main จะรับจำนวนชุดทดสอบ test_cases แล้ววนลูปเรียก solve_test_case ทีละชุด ภายใน solve_test_case จะรับจำนวนจุด point_count และเก็บพิกัดเป็น tuple (pos_x, pos_y) ลงในลิสต์ points จากนั้นใช้ points.sort(key=get_sort_key) โดยฟังก์ชัน get_sort_key คืนค่าเป็น tuple (pos_x + pos_y, -pos_y) ซึ่งทำให้ Python เรียงตามผลรวม x+y จากน้อยไปมากเป็นลำดับแรก และหากผลรวมเท่ากันจะเรียงตามค่า y จากมากไปน้อยอัตโนมัติเนื่องจากมีเครื่องหมายลบนำหน้า จากนั้นวนลูปแสดงผลพิกัดออกมาทีละบรรทัด ซึ่งรองรับทั้งกรณีพิกัดติดลบและกรณีที่มีผลรวมเท่ากันหลายจุดได้อย่างถูกต้อง
```
