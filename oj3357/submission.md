ไฟล์นี้ต้องเขียนโดยนักศึกษาด้วยคำพูดของตนเอง

ใช้ template นี้เฉพาะกับโจทย์ OJ ที่ถูกระบุว่าต้องส่ง learning log เท่านั้น

ห้ามให้ AI เขียนไฟล์นี้แทนคุณ AI อาจช่วยตรวจ grammar, formatting หรือความชัดเจนได้ หลังจากที่คุณเขียนเนื้อหาของตนเองแล้ว

ถ้าใช้ AI กับโจทย์ learning-log-required นี้ ต้องทำไฟล์ `ai_reflection.md` ด้วย

## 2. ความเข้าใจโจทย์ของฉัน

เขียนโจทย์ด้วยคำพูดของตนเอง

ให้อธิบาย input, output และ constraints สำคัญด้วย

ถ้ายังไม่เข้าใจโจทย์ทั้งหมด ให้เขียนสิ่งที่เข้าใจในตอนนี้ ความเข้าใจอาจยังไม่ครบหรืออาจผิดได้ แต่ต้องพยายามอธิบายอย่างจริงใจ

```text
โจทย์ให้นับจำนวนยีราฟที่ไม่โดนแย่งอาหาร โดยยีราฟที่ไม่โดนแย่งอาหารคือตัวที่มีความสูงมากกว่าเพื่อนตัวที่อยู่ติดกันทั้งด้านซ้ายและด้านขวา (จุดยอดท้องถิ่น หรือ local peak) สำหรับตัวแรกสุดจะพิจารณาเทียบกับตัวขวาเพียงตัวเดียว และตัวสุดท้ายจะพิจารณาเทียบกับตัวซ้ายเพียงตัวเดียว เมื่อตรวจครบทุกตัวแล้วให้แสดงจำนวนรวมของยีราฟที่กินอิ่มออกมาในบรรทัดเดียว

Input:
บรรทัดแรกรับจำนวนเต็มบวก total แทนจำนวนยีราฟทั้งหมด N ตัว (1 <= N <= 100)
จากนั้นอีก N บรรทัด แต่ละบรรทัดรับจำนวนเต็มบวกความสูงของยีราฟแต่ละตัว (1 <= H <= 1000)

Output:
แสดงผลจำนวนเต็ม 1 บรรทัด เป็นจำนวนยีราฟที่ไม่โดนแย่งกิน

Constraints:
1 <= N <= 100
1 <= H <= 1000
ไม่มียีราฟที่มีความสูงเท่ากันอยู่ติดกัน
หากมียีราฟเพียงตัวเดียว (N = 1) ถือว่ากินอิ่มเสมอ
```

## 3. แผนแรกของฉัน

เขียนแผนแรกก่อนรับความช่วยเหลือจาก AI เพื่อน TA ผู้สอน หรือก่อนสรุป code สุดท้าย

ถ้าใช้ AI ให้เขียนแผนที่มีอยู่ก่อน prompt แรกที่ถาม AI

ถ้าถามเพื่อน TA หรือผู้สอน ให้เขียนแผนที่มีอยู่ก่อนถาม

ถ้าไม่ได้ใช้ AI และไม่ได้ขอความช่วยเหลือจากคน ให้เขียนแผนที่มีอยู่ก่อนหรือระหว่างเริ่มเขียน code

แผนนี้เขียนแบบคร่าว ๆ ได้ อาจยังไม่สมบูรณ์หรืออาจต่างจากวิธีสุดท้าย

สามารถเขียนเป็น pseudocode, flowchart idea หรือขั้นตอนความคิดได้

```text
Step 1: รับค่าจำนวนเต็ม total จากบรรทัดแรก
Step 2: รับค่าความสูงของยีราฟจำนวน total บรรทัดเข้ามาเก็บลงในลิสต์ heights โดยใช้ list comprehension [int(input()) for _ in range(total)]
Step 3: ตรวจสอบกรณีพิเศษ ถ้า total == 1 ให้พิมพ์ 1 แล้ว return จบการทำงานทันที
Step 4: กำหนดตัวแปรตัวนับ count = 0
Step 5: วนลูปตามดัชนี idx ตั้งแต่ 0 ถึง total - 1
Step 6: ในแต่ละรอบ ให้ตั้งค่า is_peak = True
Step 7: ถ้ามีตัวทางซ้าย (idx > 0) และความสูงปัจจุบันน้อยกว่าหรือเท่ากับตัวทางซ้าย (heights[idx] <= heights[idx - 1]) ให้ is_peak = False
Step 8: ถ้ามีตัวทางขวา (idx < total - 1) และความสูงปัจจุบันน้อยกว่าหรือเท่ากับตัวทางขวา (heights[idx] <= heights[idx + 1]) ให้ is_peak = False
Step 9: ถ้าตรวจสอบแล้ว is_peak ยังคงเป็น True ให้เพิ่ม count += 1
Step 10: เมื่อตรวจครบทุกตัวแล้ว ให้พิมพ์ค่า count ออกมา

ก่อนเริ่มเขียน ฉันคิดว่าจะแยกเงื่อนไขตัวแรก ตัวกลาง และตัวสุดท้ายออกจากกันเป็นหลายเคส แต่การใช้ตัวแปร flag (is_peak) ร่วมกับการตรวจสอบขอบเขตดัชนี idx > 0 และ idx < total - 1 ทำให้เขียนโค้ดตรวจสอบเพื่อนบ้านซ้ายขวาได้กระชับและไม่หลุดขอบเขต list
```

## 4. วิธีสุดท้ายที่ใช้จริง

อธิบายสั้น ๆ ว่า algorithm หรือวิธีสุดท้ายที่ใช้จริงใน code ที่ส่งคืออะไร

หัวข้อนี้ต่างจาก Section 3:

- Section 3 คือแผนแรกก่อนใช้ AI ก่อนรับความช่วยเหลือจากคน หรือก่อนเขียน code สุดท้าย
- Section 4 คือวิธีสุดท้ายที่ใช้ใน solution จริง
- ถ้าวิธีสุดท้ายเหมือนกับแผนแรก ให้เขียนว่าเหมือนกัน และอธิบายสั้น ๆ ว่าทำไม

ห้ามคัดลอกคำอธิบายจาก AI

ห้ามคัดลอกคำอธิบายจากคนอื่น

```text
วิธีสุดท้ายของฉันเหมือนกับแผนที่วางไว้ โดยรับค่า total และเก็บความสูงยีราฟทั้งหมดลงในลิสต์ heights ด้วย list comprehension จากนั้นดักเงื่อนไขพิเศษ total == 1 ให้ตอบ 1 ทันที สำหรับกรณีทั่วไปจะใช้ลูป for ตรวจสอบดัชนีทีละตัว โดยตั้ง is_peak = True ไว้ก่อน แล้วเช็คเงื่อนไข heights[idx] <= heights[idx - 1] เมื่อมีตัวซ้าย (idx > 0) และเช็ค heights[idx] <= heights[idx + 1] เมื่อมีตัวขวา (idx < total - 1) หากไม่ผ่านเกณฑ์จะเปลี่ยนเป็น False แต่ถ้าผ่านทั้งคู่ก็จะบวก count เพิ่มทีละ 1 แล้วสั่งพิมพ์ผลรวม count ในตอนท้าย ซึ่งครอบคลุมทั้งตัวขอบซ้ายสุด ขวาสุด และตัวตรงกลางได้อย่างถูกต้อง
```

## 7. ความช่วยเหลือจากคน / การร่วมมือ

ได้ถามเพื่อน TA ผู้สอน หรือบุคคลอื่นเพื่อขอความช่วยเหลือในโจทย์นี้หรือไม่

```text

```

ถ้าใช่ ให้อธิบายสั้น ๆ ว่าได้รับความช่วยเหลือแบบใด

ตัวอย่างที่อนุญาต:

- อธิบายความหมายของโจทย์
- อธิบาย concept การเขียนโปรแกรม
- ให้ hint เกี่ยวกับแนวทาง
- คุยเรื่อง debugging
- คุยเรื่อง test cases
- ช่วยอธิบาย error message

สิ่งที่ไม่อนุญาต:

- คัดลอก code ของผู้อื่น
- ส่ง solution ของผู้อื่น
- ขอให้ผู้อื่นเขียน solution ให้
- ใช้ OJ submission ของผู้อื่น
- ขอให้ผู้อื่นส่ง OJ แทน
