# บันทึกการแก้โจทย์

ไฟล์นี้ต้องเขียนโดยนักศึกษาด้วยคำพูดของตนเอง

ใช้ template นี้เฉพาะกับโจทย์ OJ ที่ถูกระบุว่าต้องส่ง learning log เท่านั้น

ห้ามให้ AI เขียนไฟล์นี้แทนคุณ AI อาจช่วยตรวจ grammar, formatting หรือความชัดเจนได้ หลังจากที่คุณเขียนเนื้อหาของตนเองแล้ว

ถ้าใช้ AI กับโจทย์ learning-log-required นี้ ต้องทำไฟล์ `ai_reflection.md` ด้วย

## 1. ข้อมูล OJ

หมายเลข/ชื่อโจทย์ OJ:

```text
OJ3232 - [LEARNING LOGS] กบน้อยกระโดด
```

OJ submission ID ถ้ามีการส่งแล้ว:

```text
647535
```

สถานะ OJ:

```text
Pass
```

เวลาที่ใช้คิดและทำโจทย์ด้วยตนเอง:

```text
15-30 minutes
```

เลือกหนึ่งข้อ:

```text
0-15 minutes
15-30 minutes
30-60 minutes
1-3 hours
3-6 hours
6-24 hours
1-3 days
4-7 days
1-4 weeks
More than 4 weeks
```

วิธีนับเวลา:

- นับเฉพาะเวลาที่ตั้งใจทำโจทย์นี้ด้วยตนเองจริง ๆ
- เริ่มนับตั้งแต่ตอนที่อ่านโจทย์ครั้งแรก
- ไม่นับเวลาพัก กินข้าว เรียน นอน เวลาที่ทำโจทย์อื่น หรือเวลาที่ไม่ได้ทำโจทย์นี้
- ถ้าใช้ AI ให้นับเฉพาะเวลาที่ทำด้วยตนเองก่อน prompt แรกที่ถาม AI
- ถ้าถามเพื่อน TA หรือผู้สอน ให้นับเฉพาะเวลาที่ทำด้วยตนเองก่อนขอความช่วยเหลือครั้งแรก
- ถ้าใช้ทั้ง AI และความช่วยเหลือจากคน ให้นับเฉพาะเวลาที่ทำด้วยตนเองก่อนขอความช่วยเหลือจากภายนอกครั้งแรก ไม่ว่าจะเป็น AI หรือคน
- ถ้าไม่ได้ใช้ AI และไม่ได้ขอความช่วยเหลือจากคน ให้นับเวลาถึงก่อนเขียน `submission.md`
- ประมาณเวลาได้ แต่ต้องซื่อสัตย์

## 2. ความเข้าใจโจทย์ของฉัน

เขียนโจทย์ด้วยคำพูดของตนเอง

ให้อธิบาย input, output และ constraints สำคัญด้วย

ถ้ายังไม่เข้าใจโจทย์ทั้งหมด ให้เขียนสิ่งที่เข้าใจในตอนนี้ ความเข้าใจอาจยังไม่ครบหรืออาจผิดได้ แต่ต้องพยายามอธิบายอย่างจริงใจ

```text
โจทย์ให้คำนวณหาจำนวนครั้งที่น้อยที่สุดที่กบต้องกระโดดเพื่อให้ได้ระยะทางรวมอย่างน้อย Y เมตร โดยการกระโดดครั้งแรกได้ระยะทาง X เมตร และในแต่ละครั้งถัดไประยะทางจะลดลงทีละ 2 เมตรเสมอ (ต้องมีระยะกระโดดมากกว่า 0 ถึงจะกระโดดได้) หากกระโดดจนระยะทางลดเหลือ 0 แล้วแต่ยังสะสมระยะทางไม่ถึง Y เมตร ให้ตอบ -1

Input:
บรรทัดเดียวรับจำนวนเต็มบวก 2 จำนวน คือ X (ระยะทางกระโดดครั้งแรก) และ Y (ระยะทางเป้าหมาย) คั่นด้วยช่องว่าง

Output:
แสดงผลจำนวนเต็ม 1 บรรทัด เป็นจำนวนครั้งขั้นต่ำที่กระโดดจนได้ระยะทางรวมอย่างน้อย Y เมตร หรือพิมพ์ -1 หากไม่สามารถกระโดดไปถึงเป้าหมายได้

Constraints:
1 <= X <= 1,000
1 <= Y <= 100,000
ระยะการกระโดดแต่ละครั้งจะลดลงทีละ 2 เมตร และกระโดดได้เฉพาะเมื่อระยะทางของการกระโดดครั้งนั้นมีค่ามากกว่า 0 เท่านั้น
```

## 3. แผนแรกของฉัน

เขียนแผนแรกก่อนรับความช่วยเหลือจาก AI เพื่อน TA ผู้สอน หรือก่อนสรุป code สุดท้าย

ถ้าใช้ AI ให้เขียนแผนที่มีอยู่ก่อน prompt แรกที่ถาม AI

ถ้าถามเพื่อน TA หรือผู้สอน ให้เขียนแผนที่มีอยู่ก่อนถาม

ถ้าไม่ได้ใช้ AI และไม่ได้ขอความช่วยเหลือจากคน ให้เขียนแผนที่มีอยู่ก่อนหรือระหว่างเริ่มเขียน code

แผนนี้เขียนแบบคร่าว ๆ ได้ อาจยังไม่สมบูรณ์หรืออาจต่างจากวิธีสุดท้าย

สามารถเขียนเป็น pseudocode, flowchart idea หรือขั้นตอนความคิดได้

```text
Step 1: รับค่าจำนวนเต็ม x และ y จาก input บรรทัดเดียวโดยใช้ map(int, input().split())
Step 2: กำหนดตัวแปร current_jump = x เพื่อเก็บระยะกระโดดของครั้งปัจจุบัน, total_distance = 0 เพื่อเก็บระยะทางสะสม และ jump_count = 0 เพื่อเก็บจำนวนครั้งที่กระโดด
Step 3: ใช้ลูป while ทำงานเมื่อ current_jump > 0 (ยังมีแรงกระโดดไปข้างหน้า)
Step 4: ในแต่ละรอบ ให้เพิ่มระยะทางสะสม total_distance += current_jump และนับจำนวนครั้งเพิ่มขึ้น jump_count += 1
Step 5: ตรวจสอบเงื่อนไข ถ้า total_distance >= y ให้พิมพ์ jump_count แล้วใช้ return เพื่อจบการทำงานของโปรแกรมทันที
Step 6: ลดระยะกระโดดสำหรับครั้งถัดไปลง 2 เมตรด้วย current_jump -= 2
Step 7: ถ้าออกจากลูปแล้ว (current_jump <= 0) แสดงว่าไม่สามารถกระโดดถึงระยะ y ได้ ให้พิมพ์ -1

ก่อนเริ่มเขียน ฉันคิดว่าจะใช้สูตรอนุกรมเลขคณิตเพื่อคำนวณผลรวมระยะทางสูงสุดก่อน แต่เนื่องจากค่า X มีค่าไม่เกิน 1,000 การจำลองการกระโดดทีละครั้งด้วยลูป while จึงทำงานได้เร็วมากและทำให้ตรวจสอบเงื่อนไขระยะรวม >= Y ได้โดยตรง
```

## 4. วิธีสุดท้ายที่ใช้จริง

อธิบายสั้น ๆ ว่า algorithm หรือวิธีสุดท้ายที่ใช้จริงใน code ที่ส่งคืออะไร

หัวข้อนี้ต่างจาก Section 3:

- Section 3 คือแผนแรกก่อนใช้ AI ก่อนรับความช่วยเหลือจากคน หรือก่อนเขียน code สุดท้าย
- Section 4 คือวิธีสุดท้ายที่ใช้ใน solution จริง
- ถ้าวิธีสุดท้ายเหมือนกับแผนแรก ให้เขียนว่าเหมือนกัน และอธิบายสั้น ๆ ว่าทำไม

ห้ามคัดลอกคำอธิบายจาก AI

ห้ามคัดลอกคำอธิบายจากคนอื่น

```text
วิธีสุดท้ายของฉันเหมือนกับแผนที่วางไว้ โดยรับค่า x และ y เข้ามา จากนั้นตั้ง current_jump = x, total_distance = 0 และ jump_count = 0 แล้วใช้ลูป while current_jump > 0 เพื่อสะสมระยะทางและนับจำนวนก้าวในแต่ละรอบ พร้อมตรวจเช็คว่าถ้า total_distance >= y ให้พิมพ์ jump_count แล้วสั่ง return ออกจากฟังก์ชันทันที แต่ละรอบจะลด current_jump ลง 2 เมตร หากกระโดดจนหมดแรงแล้วยังไม่ถึงเป้าหมาย โปรแกรมจะหลุดลูปแล้วสั่งพิมพ์ -1 ออกมา ซึ่งรองรับทั้งกรณีที่กระโดดครั้งเดียวถึง และกรณีที่ไม่สามารถไปถึงเป้าหมายได้
```

## 7. ความช่วยเหลือจากคน / การร่วมมือ

ได้ถามเพื่อน TA ผู้สอน หรือบุคคลอื่นเพื่อขอความช่วยเหลือในโจทย์นี้หรือไม่

```text
No
```

ถ้าใช่ ให้อธิบายสั้น ๆ ว่าได้รับความช่วยเหลือแบบใด

ตัวอย่างที่อนุญาต:

- อธิบายความหมายของโจทย์
- อธิบาย concept การเขียนโปรแกรม
- ให้ hint เกี่ยวกับแนวทาง
- คุยเรื่อง debugging
- คุยเรื่อง test cases
- ช่วยอธิบาย error message

สิ่งที่ไม่อนุญาต:

- คัดลอก code ของผู้อื่น
- ส่ง solution ของผู้อื่น
- ขอให้ผู้อื่นเขียน solution ให้
- ใช้ OJ submission ของผู้อื่น
- ขอให้ผู้อื่นส่ง OJ แทน
