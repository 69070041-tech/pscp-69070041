# บันทึกการแก้โจทย์

ไฟล์นี้ต้องเขียนโดยนักศึกษาด้วยคำพูดของตนเอง

ใช้ template นี้เฉพาะกับโจทย์ OJ ที่ถูกระบุว่าต้องส่ง learning log เท่านั้น

ห้ามให้ AI เขียนไฟล์นี้แทนคุณ AI อาจช่วยตรวจ grammar, formatting หรือความชัดเจนได้ หลังจากที่คุณเขียนเนื้อหาของตนเองแล้ว

ถ้าใช้ AI กับโจทย์ learning-log-required นี้ ต้องทำไฟล์ `ai_reflection.md` ด้วย

## 1. ข้อมูล OJ

หมายเลข/ชื่อโจทย์ OJ:

```text
OJ3360 - [LEARNING LOGS] หั่นขนมปัง
```

OJ submission ID ถ้ามีการส่งแล้ว:

```text
678471
```

สถานะ OJ:

```text
Pass
```

เวลาที่ใช้คิดและทำโจทย์ด้วยตนเอง:

```text
30-60 minutes
```

เลือกหนึ่งข้อ:

```text
0-15 minutes
15-30 minutes
30-60 minutes
1-3 hours
3-6 hours
6-24 hours
1-3 days
4-7 days
1-4 weeks
More than 4 weeks
```

วิธีนับเวลา:

- นับเฉพาะเวลาที่ตั้งใจทำโจทย์นี้ด้วยตนเองจริง ๆ
- เริ่มนับตั้งแต่ตอนที่อ่านโจทย์ครั้งแรก
- ไม่นับเวลาพัก กินข้าว เรียน นอน เวลาที่ทำโจทย์อื่น หรือเวลาที่ไม่ได้ทำโจทย์นี้
- ถ้าใช้ AI ให้นับเฉพาะเวลาที่ทำด้วยตนเองก่อน prompt แรกที่ถาม AI
- ถ้าถามเพื่อน TA หรือผู้สอน ให้นับเฉพาะเวลาที่ทำด้วยตนเองก่อนขอความช่วยเหลือครั้งแรก
- ถ้าใช้ทั้ง AI และความช่วยเหลือจากคน ให้นับเฉพาะเวลาที่ทำด้วยตนเองก่อนขอความช่วยเหลือจากภายนอกครั้งแรก ไม่ว่าจะเป็น AI หรือคน
- ถ้าไม่ได้ใช้ AI และไม่ได้ขอความช่วยเหลือจากคน ให้นับเวลาถึงก่อนเขียน `submission.md`
- ประมาณเวลาได้ แต่ต้องซื่อสัตย์

## 2. ความเข้าใจโจทย์ของฉัน

เขียนโจทย์ด้วยคำพูดของตนเอง

ให้อธิบาย input, output และ constraints สำคัญด้วย

ถ้ายังไม่เข้าใจโจทย์ทั้งหมด ให้เขียนสิ่งที่เข้าใจในตอนนี้ ความเข้าใจอาจยังไม่ครบหรืออาจผิดได้ แต่ต้องพยายามอธิบายอย่างจริงใจ

```text
โจทย์ให้คำนวณหาพื้นที่ของชิ้นขนมปังที่ใหญ่ที่สุด 2 อันดับแรก หลังจากที่ขนมปังขนาดกว้าง W สูง H ถูกหั่นด้วยใบมีดแนวตั้ง M ใบ (พิกัด X) และใบมีดแนวนอน N ใบ (พิกัด Y) ซึ่งรอยตัดแต่ละแนวจะแบ่งขนมปังออกเป็นชิ้นย่อยรูปสี่เหลี่ยมผืนผ้า โดยให้แสดงผลพื้นที่ชิ้นที่ใหญ่ที่สุดและชิ้นที่ใหญ่เป็นอันดับสองคั่นด้วยช่องว่าง (ทั้งสองชิ้นสามารถมีขนาดเท่ากันได้)

Input:
บรรทัดที่ 1 รับจำนวนเต็ม 4 จำนวน คือ W, H, M, N แทนความกว้าง ความสูง จำนวนมีดแนวตั้ง และจำนวนมีดแนวนอน
บรรทัดที่ 2 รับจำนวนเต็ม M จำนวน แทนพิกัดรอยตัดแนวตั้ง (X1 ถึง XM)
บรรทัดที่ 3 รับจำนวนเต็ม N จำนวน แทนพิกัดรอยตัดแนวนอน (Y1 ถึง YN)

Output:
แสดงผลจำนวนเต็ม 2 จำนวนในบรรทัดเดียว คั่นด้วยช่องว่าง แทนพื้นที่ของขนมปังชิ้นย่อยที่ใหญ่ที่สุด 2 อันดับแรก โดยพิมพ์ค่าที่มากกว่าก่อน

Constraints:
1 <= W, H <= 10,000
1 <= M, N <= 1,000
0 < Xi < W และเรียงจากน้อยไปมากเสมอ
0 < Yi < H และเรียงจากน้อยไปมากเสมอ
ชิ้นขนมปังที่ใหญ่ที่สุด 2 อันดับแรกอาจมีขนาดเท่ากันได้
```

## 3. แผนแรกของฉัน

เขียนแผนแรกก่อนรับความช่วยเหลือจาก AI เพื่อน TA ผู้สอน หรือก่อนสรุป code สุดท้าย

ถ้าใช้ AI ให้เขียนแผนที่มีอยู่ก่อน prompt แรกที่ถาม AI

ถ้าถามเพื่อน TA หรือผู้สอน ให้เขียนแผนที่มีอยู่ก่อนถาม

ถ้าไม่ได้ใช้ AI และไม่ได้ขอความช่วยเหลือจากคน ให้เขียนแผนที่มีอยู่ก่อนหรือระหว่างเริ่มเขียน code

แผนนี้เขียนแบบคร่าว ๆ ได้ อาจยังไม่สมบูรณ์หรืออาจต่างจากวิธีสุดท้าย

สามารถเขียนเป็น pseudocode, flowchart idea หรือขั้นตอนความคิดได้

```text
Step 1: รับค่า W, H, M, N จากบรรทัดแรก โดยแปลงเป็นจำนวนเต็มเก็บในตัวแปร width, height และละเว้น M, N
Step 2: รับพิกัดรอยตัดแนวตั้งและแนวนอนจากบรรทัดที่สองและสาม เก็บในลิสต์ x_cuts และ y_cuts
Step 3: สร้างฟังก์ชัน get_widths นำพิกัดรอยตัดมารวมกับจุดขอบ (0 และ total_length) แล้วคำนวณหาระยะห่างระหว่างรอยตัดแต่ละช่วง (points[idx] - points[idx - 1])
Step 4: นำความกว้างย่อย (widths) และความสูงย่อย (heights) ทั้งหมดมาเรียงลำดับจากมากไปน้อยด้วย sorted(..., reverse=True)
Step 5: ดึงความกว้างที่ยาวที่สุด 2 ลำดับแรก (w1, w2) และความสูงที่ยาวที่สุด 2 ลำดับแรก (h1, h2)
Step 6: คำนวณพื้นที่ที่ใหญ่ที่สุด max_area = w1 * h1
Step 7: คำนวณพื้นที่อันดับสอง second_area = max(w1 * h2, w2 * h1)
Step 8: แสดงผลลัพธ์ f"{max_area} {second_area}" ในบรรทัดเดียว

ก่อนเริ่มเขียน ฉันคิดว่าจะจับคู่ความกว้างและความสูงทุกช่วงมาคูณกันทั้งหมดเพื่อหาพื้นที่ทุกชิ้นแล้วค่อย sort แต่เนื่องจาก M และ N มีได้ถึง 1,000 การคูณทุกคู่จะได้พื้นที่ถึง 1,000,000 ชิ้น ซึ่งเปลืองเวลาโดยไม่จำเป็น การเลือกเฉพาะความกว้างและความสูงที่ยาวที่สุด 2 ลำดับแรกมาพิจารณา ช่วยให้หาพื้นที่ชิ้นที่ใหญ่ที่สุด 2 อันดับแรกได้ทันทีใน O(1) หลังจากการเรียงลำดับ
```

## 4. วิธีสุดท้ายที่ใช้จริง

อธิบายสั้น ๆ ว่า algorithm หรือวิธีสุดท้ายที่ใช้จริงใน code ที่ส่งคืออะไร

หัวข้อนี้ต่างจาก Section 3:

- Section 3 คือแผนแรกก่อนใช้ AI ก่อนรับความช่วยเหลือจากคน หรือก่อนเขียน code สุดท้าย
- Section 4 คือวิธีสุดท้ายที่ใช้ใน solution จริง
- ถ้าวิธีสุดท้ายเหมือนกับแผนแรก ให้เขียนว่าเหมือนกัน และอธิบายสั้น ๆ ว่าทำไม

ห้ามคัดลอกคำอธิบายจาก AI

ห้ามคัดลอกคำอธิบายจากคนอื่น

```text
วิธีสุดท้ายของฉันเหมือนกับแผนที่วางไว้ โดยรับข้อมูล W, H และพิกัดรอยตัดแกน X กับแกน Y เข้ามา จากนั้นใช้ฟังก์ชัน get_widths เติมขอบ 0 กับขอบเขตสูงสุดเข้าไปเพื่อหาความยาวของแต่ละช่วงย่อยด้วย list comprehension แล้วนำผลลัพธ์มาเรียงลำดับจากมากไปน้อยด้วย sorted(..., reverse=True) ดึงค่า 2 อันดับแรกของทั้งแกนกว้าง (w1, w2) และแกนสูง (h1, h2) ออกมา เพื่อคำนวณพื้นที่อันดับหนึ่งจาก w1 * h1 และอันดับสองจาก max(w1 * h2, w2 * h1) แล้วสั่งพิมพ์ออกมาคั่นด้วยช่องว่าง ซึ่งทำงานได้อย่างรวดเร็วและรองรับกรณีที่พื้นที่สองอันดับแรกมีขนาดเท่ากันได้อย่างถูกต้อง
```

## 7. ความช่วยเหลือจากคน / การร่วมมือ

ได้ถามเพื่อน TA ผู้สอน หรือบุคคลอื่นเพื่อขอความช่วยเหลือในโจทย์นี้หรือไม่


- อธิบายความหมายของโจทย์
- อธิบาย concept การเขียนโปรแกรม
- ให้ hint เกี่ยวกับแนวทาง
- คุยเรื่อง debugging
- คุยเรื่อง test cases
- ช่วยอธิบาย error message

สิ่งที่ไม่อนุญาต:

- คัดลอก code ของผู้อื่น
- ส่ง solution ของผู้อื่น
- ขอให้ผู้อื่นเขียน solution ให้
- ใช้ OJ submission ของผู้อื่น
- ขอให้ผู้อื่นส่ง OJ แทน
