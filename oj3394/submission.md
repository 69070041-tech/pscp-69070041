# บันทึกการแก้โจทย์

ไฟล์นี้ต้องเขียนโดยนักศึกษาด้วยคำพูดของตนเอง

ใช้ template นี้เฉพาะกับโจทย์ OJ ที่ถูกระบุว่าต้องส่ง learning log เท่านั้น

ห้ามให้ AI เขียนไฟล์นี้แทนคุณ AI อาจช่วยตรวจ grammar, formatting หรือความชัดเจนได้ หลังจากที่คุณเขียนเนื้อหาของตนเองแล้ว

ถ้าใช้ AI กับโจทย์ learning-log-required นี้ ต้องทำไฟล์ `ai_reflection.md` ด้วย

---

## 1. ข้อมูล OJ

หมายเลข/ชื่อโจทย์ OJ:

```text
OJ3394 - [LEARNING LOGS] ส่งต่อ
```

OJ submission ID ถ้ามีการส่งแล้ว:

```text
679733
```

สถานะ OJ:

```text
Pass
```

เวลาที่ใช้คิดและทำโจทย์ด้วยตนเอง:

```text
30-60 minutes
```

เลือกหนึ่งข้อ:

```text
0-15 minutes
15-30 minutes
30-60 minutes
1-3 hours
3-6 hours
6-24 hours
1-3 days
4-7 days
1-4 weeks
More than 4 weeks
```

วิธีนับเวลา:

- นับเฉพาะเวลาที่ตั้งใจทำโจทย์นี้ด้วยตนเองจริง ๆ
- เริ่มนับตั้งแต่ตอนที่อ่านโจทย์ครั้งแรก
- ไม่นับเวลาพัก กินข้าว เรียน นอน เวลาที่ทำโจทย์อื่น หรือเวลาที่ไม่ได้ทำโจทย์นี้
- ถ้าใช้ AI ให้นับเฉพาะเวลาที่ทำด้วยตนเองก่อน prompt แรกที่ถาม AI
- ถ้าถามเพื่อน TA หรือผู้สอน ให้นับเฉพาะเวลาที่ทำด้วยตนเองก่อนขอความช่วยเหลือครั้งแรก
- ถ้าใช้ทั้ง AI และความช่วยเหลือจากคน ให้นับเฉพาะเวลาที่ทำด้วยตนเองก่อนขอความช่วยเหลือจากภายนอกครั้งแรก ไม่ว่าจะเป็น AI หรือคน
- ถ้าไม่ได้ใช้ AI และไม่ได้ขอความช่วยเหลือจากคน ให้นับเวลาถึงก่อนเขียน `submission.md`
- ประมาณเวลาได้ แต่ต้องซื่อสัตย์

## 2. ความเข้าใจโจทย์ของฉัน

เขียนโจทย์ด้วยคำพูดของตนเอง

ให้อธิบาย input, output และ constraints สำคัญด้วย

ถ้ายังไม่เข้าใจโจทย์ทั้งหมด ให้เขียนสิ่งที่เข้าใจในตอนนี้ ความเข้าใจอาจยังไม่ครบหรืออาจผิดได้ แต่ต้องพยายามอธิบายอย่างจริงใจ

```text
โจทย์ให้หาจำนวนนักเรียนทั้งหมดที่ได้รับข้อความจากการส่งต่อ โดยเริ่มต้นส่งข้อความให้นักเรียนคนที่ S แล้วนักเรียนแต่ละคนจะส่งต่อข้อความให้เพื่อนสนิทตามหมายเลขที่ระบุไว้เพียงคนเดียวเท่านั้น (ถ้าไม่ส่งต่อให้ใครเลยจะระบุเป็น 0) การส่งต่อจะหยุดลงเมื่อส่งไปถึงคนที่ไม่มีการส่งต่อ (เจอเลข 0) หรือข้อความถูกส่งวนกลับมาหานักเรียนคนที่เคยได้รับข้อความไปแล้ว ซึ่งนักเรียนจะไม่ส่งซ้ำอีก ให้แสดงผลจำนวนคนที่ได้รับข้อความที่ไม่ซ้ำกันทั้งหมด

Input:
บรรทัดแรกรับจำนวนเต็มบวก 2 จำนวน คือ N (จำนวนนักเรียนทั้งหมด) และ S (หมายเลขนักเรียนคนแรกที่ได้รับข้อความ) คั่นด้วยช่องว่าง
จากนั้นอีก N บรรทัด (บรรทัดที่ 1+i สำหรับ i ตั้งแต่ 1 ถึง N) รับจำนวนเต็ม 1 จำนวน แทนหมายเลขเพื่อนที่นักเรียนคนที่ i จะส่งต่อให้ (ถ้าไม่ส่งต่อให้ใครจะเป็น 0)

Output:
แสดงผลจำนวนเต็ม 1 บรรทัด เป็นจำนวนนักเรียนที่ได้รับข้อความทั้งหมดผ่านการส่งต่อ

Constraints:
1 <= N <= 1,000
1 <= S <= N
นักเรียนแต่ละคนส่งต่อให้คนอื่นไม่เกิน 1 คน และไม่ส่งต่อให้ตัวเอง
หากข้อความวนกลับมาหาคนที่เคยได้รับแล้ว การส่งต่อจะหยุดลงทันที
```

## 3. แผนแรกของฉัน

เขียนแผนแรกก่อนรับความช่วยเหลือจาก AI เพื่อน TA ผู้สอน หรือก่อนสรุป code สุดท้าย

ถ้าใช้ AI ให้เขียนแผนที่มีอยู่ก่อน prompt แรกที่ถาม AI

ถ้าถามเพื่อน TA หรือผู้สอน ให้เขียนแผนที่มีอยู่ก่อนถาม

ถ้าไม่ได้ใช้ AI และไม่ได้ขอความช่วยเหลือจากคน ให้เขียนแผนที่มีอยู่ก่อนหรือระหว่างเริ่มเขียน code

แผนนี้เขียนแบบคร่าว ๆ ได้ อาจยังไม่สมบูรณ์หรืออาจต่างจากวิธีสุดท้าย

สามารถเขียนเป็น pseudocode, flowchart idea หรือขั้นตอนความคิดได้

```text
Step 1: รับข้อมูลบรรทัดแรกแยกเป็น total_students (N) และ start_student (S) แปลงเป็น int
Step 2: สร้างลิสต์ forward_targets ขนาด total_students + 1 เริ่มต้นด้วย 0 เพื่อเก็บเป้าหมายการส่งต่อของนักเรียนแต่ละคนแบบ 1-indexed
Step 3: วนลูป student_id ตั้งแต่ 1 ถึง total_students เพื่อรับหมายเลข target_id ที่นักเรียนคนนั้นจะส่งต่อให้ แล้วบันทึกลงใน forward_targets[student_id]
Step 4: สร้างฟังก์ชัน count_recipients โดยรับ start_student และ forward_targets เข้ามาประมวลผล
Step 5: สร้างเซต visited_students = set() เพื่อเก็บหมายเลขนักเรียนที่ได้รับข้อความแล้ว และตั้ง current_student = start_student
Step 6: ใช้ลูป while ทำงานเมื่อ current_student != 0 และ current_student ยังไม่อยู่ใน visited_students
Step 7: ในแต่ละรอบ เพิ่ม current_student เข้า visited_students จากนั้นเปลี่ยน current_student ให้เป็นคนถัดไปด้วย forward_targets[current_student]
Step 8: เมื่อหลุดลูป (เจอ 0 หรือเจอคนที่เคยส่งแล้ว) ให้ส่งคืนค่า len(visited_students) แล้วพิมพ์ผลลัพธ์ออกมาในบรรทัดเดียว

ก่อนเริ่มเขียน ฉันคิดว่าจะใช้วิธีวนลูปและใช้ตัวแปรนับพร้อมกับ array ขนาด N เพื่อเช็คการเข้าชม แต่การใช้ set ในการบันทึกคนที่เคยได้รับข้อความ (visited_students) ช่วยให้ตรวจสอบการวนซ้ำได้ใน O(1) และหาจำนวนคนทั้งหมดได้ทันทีจาก len()
```

## 4. วิธีสุดท้ายที่ใช้จริง

อธิบายสั้น ๆ ว่า algorithm หรือวิธีสุดท้ายที่ใช้จริงใน code ที่ส่งคืออะไร

หัวข้อนี้ต่างจาก Section 3:

- Section 3 คือแผนแรกก่อนใช้ AI ก่อนรับความช่วยเหลือจากคน หรือก่อนเขียน code สุดท้าย
- Section 4 คือวิธีสุดท้ายที่ใช้ใน solution จริง
- ถ้าวิธีสุดท้ายเหมือนกับแผนแรก ให้เขียนว่าเหมือนกัน และอธิบายสั้น ๆ ว่าทำไม

ห้ามคัดลอกคำอธิบายจาก AI

ห้ามคัดลอกคำอธิบายจากคนอื่น

```text
วิธีสุดท้ายของฉันเหมือนกับแผนที่วางไว้ โดยรับจำนวนนักเรียน total_students และจุดเริ่มต้น start_student จากนั้นรับเป้าหมายการส่งต่อทีละบรรทัดมาเก็บในลิสต์ forward_targets ขนาด total_students + 1 เพื่อให้เข้าถึงด้วยหมายเลขนักเรียนได้โดยตรง จากนั้นส่งข้อมูลเข้าฟังก์ชัน count_recipients ซึ่งใช้เซต visited_students บันทึกประวัติคนที่ได้รับข้อความแล้ว และใช้ลูป while current_student and current_student not in visited_students เพื่อส่งต่อไปเรื่อยๆ ทีละคน เมื่อเจอ 0 (ไม่ส่งต่อ) หรือเจอคนที่เคยอยู่ในเซตแล้ว ลูปจะหยุดทำงานทันที แล้วคืนค่าความยาวของเซต len(visited_students) ออกมาแสดงผล ซึ่งรองรับทั้งกรณีทางตรงเส้นเดียวและกรณีเกิด cycle (วนกลับมาหาคนเดิม)
```

## 7. ความช่วยเหลือจากคน / การร่วมมือ

ได้ถามเพื่อน TA ผู้สอน หรือบุคคลอื่นเพื่อขอความช่วยเหลือในโจทย์นี้หรือไม่

```text
No
```

ถ้าใช่ ให้อธิบายสั้น ๆ ว่าได้รับความช่วยเหลือแบบใด

ตัวอย่างที่อนุญาต:

- อธิบายความหมายของโจทย์
- อธิบาย concept การเขียนโปรแกรม
- ให้ hint เกี่ยวกับแนวทาง
- คุยเรื่อง debugging
- คุยเรื่อง test cases
- ช่วยอธิบาย error message

สิ่งที่ไม่อนุญาต:

- คัดลอก code ของผู้อื่น
- ส่ง solution ของผู้อื่น
- ขอให้ผู้อื่นเขียน solution ให้
- ใช้ OJ submission ของผู้อื่น
- ขอให้ผู้อื่นส่ง OJ แทน
